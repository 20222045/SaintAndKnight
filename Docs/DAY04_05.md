## 구현 범위

`SKEnemyAgent`는 2D Rigidbody와 분리된 Hurtbox/Hitbox를 사용한다.
Patrol → Chase → Return/Patrol, Windup → Attacking → Recovery 흐름을 갖는다.
피격·전투 불능·비활성은 이동과 공격보다 우선한다.

- 시작 지점을 중심으로 정해진 범위를 왕복한다.
- 수평 탐지 거리와 높이 차이, 벽의 가림을 확인하여 플레이어를 추적한다.
- 탐지 거리보다 큰 추적 해제 거리로 경계에서의 반복 전환을 줄인다.
- 플레이어를 놓치거나 활동 반경을 넘으면 원래 자리로 돌아온다.
- 벽과 발밑 지형을 검사한다. 순찰 중 장애물/낭떠러지 앞에서는 방향을 바꾸며,
  추적·복귀 중 안전한 직선 경로가 없으면 정지한다. 점프나 우회 경로 탐색은 이번 범위가 아니다.
- 액터 몸체끼리는 밀지 않는다. 공격은 별도 트리거 판정으로만 처리한다.
- 공격 예고 중에는 이동과 방향을 고정한다. 예고 영역과 실제 Hitbox의 크기·위치는 동일하다.
  플레이어가 범위를 벗어나거나 뒤로 돌아가면 피할 수 있다.
- 타격·무적·히트스톱은 Day 2/3 공용 코드를 재사용한다. 같은 팀을 때리지 않는다.
- 플레이어 사망/적 비활성/피격 시 예고와 공격을 취소한다.
- R은 플레이어와 적 전체의 HP·시작 위치·공격 상태를 복구하고 히트스톱을 해제한다.

| 임시 수치 | A | B |
| --- | --- | --- |
| HP | 60 | 80 |
| 순찰 / 추적 속도 | 0.7 / 1.5 | 0.45 / 0.95 |
| 공격 예고 | 0.4초 | 0.85초 |
| 공격 시작 거리 | 1.1 | 1.5 |
| Hitbox 크기 | 1 × 0.85 | 1.6 × 0.85 |
| 공격 유지 / 회복 | 0.18 / 1초 | 0.25 / 1.5초 |
| 피해 | 15 | 25 |

두 적은 **기존 `training_dummy.png`를 그대로 공유하는 기능 검증용 대역**이다.
외형·세계관·최종 밸런스가 확정되었다는 뜻이 아니다. 새 그림, 모델, 스프라이트 프레임을 제작하지 않았다.
