# 시니시스타 분석의 즉시 적용 — 아트 준비 전 전투 개선

작업일: 2026-11-07 (Asia/Seoul). 사용자 승인: “지금 적용할 수 있는거 적용하고 알려줘”.

심층 조사 뒤 바로 적용 가능한 기능을 기존 프로젝트에 반영했다. 캐릭터 디자인·새 도트 프레임·Animator·3D 모델은 제작하거나 교체하지 않았다. **Day 6의 실제 도트 애니메이션 연결은 디자인 준비 대기**이며, 이번 작업은 그 전에 사용할 전투 동작 규칙과 Day 5 시연용 밸런스 개선이다.

## 플레이에서 달라진 것

- 방향키와 J를 같은 프레임에 누르면 새 방향으로 공격한다.
- 공격 준비와 유효 타격 중에는 몸과 판정이 같은 방향을 유지한다. 반대쪽 이동은 가능하므로 뒤로 물러나며 공격할 수 있다. 회복 단계에서는 방향 전환이 풀린다.
- 공격을 준비하는 동안 기존 판정 사각형이 흐리게 나타난다. 이때 Collider는 꺼져 있어 피해가 없다. 발동하면 기존 명중 표시로 바뀐다.
- 피격·사망·캐릭터 전환·컴포넌트 비활성·R 초기화가 준비 중인 공격도 취소한다. 취소된 공격이 나중에 발생하지 않는다. 전환으로 쿨타임을 없애지는 못한다.
- HP 0은 `INCAPACITATED`(전투 불능)로 표시한다. 아직 구현하지 않은 별도 정신 붕괴와 혼동하지 않게 했다. 손상 단계 0~4는 유지한다.

## 최신 Day 5 씬의 두 캐릭터

실행: `Assets/SaintKnightDay04/Scenes/Day05_EnemyPatterns.unity`.
조작: A/D 또는 방향키 이동, Space 점프, J 공격, Tab 전환, R 훈련 초기화.

| 임시 값 | 세실리아: 거리 관리 | 아델라: 근접 강타 |
| --- | --- | --- |
| 피해 | 20 | 35 |
| 준비 시간 | 0.06초 | 0.14초 |
| 유효 시간 | 0.16초 | 0.20초 |
| 공격 시작 간 최소 간격 | 0.45초 | 0.70초 |
| Hitbox 크기 | 1.2 × 0.8 | 1.0 × 0.85 |
| 중심 오프셋 | 0.9 | 0.7 |
| 중심에서 판정 앞끝까지 | 1.5 units | 1.2 units |
| 넉백 인수 | 0 | 1.8 |
| A 60HP / B 80HP 처치 타수 | 3 / 4 | 2 / 3 |

앞끝 거리는 대상 Hurtbox 크기까지 포함한 실제 명중 거리와 다르다. 넉백 1.8은 기존 피해 처리에 전달되는 수평 속도 인수이며, 기존 로직의 수직 속도 1.8도 함께 적용된다. 정확한 이동 거리는 물리와 피격 상태의 영향을 받는다.

이 수치는 **우리 게임을 위한 임시 조정값**이다. 원작의 실측값이나 최종 밸런스가 아니다. 세실리아는 더 먼 곳에서 맞힐 수 있고, 아델라는 더 가까이 가서 준비·회복 시간을 감수하는 대신 적은 타수로 적을 쓰러뜨린다. 사슬 끌기·방패 방어·패링·새 스킬은 추가하지 않았다.

Day 1/2/4 씬 파일은 보존했다. 과거 전투 씬의 프로필에는 준비 시간이 없으므로 기본값 0으로 기존 즉시 공격을 유지한다. 공용 방향 처리·취소·HP 문구 수정은 해당 컴포넌트를 사용하는 씬에 적용된다. Day 4/5 씬 재생성 코드에도 Day 5의 새 프로필을 반영했지만 이번에는 씬 전체를 재생성하지 않고 해당 직렬화 값만 수정했다.

## 구조

`SKPlayerCombat`이 준비 → 유효 → 회복의 시간 기준을 갖는다. 준비 중에는 Hitbox가 피해 없이 범위를 보여 주며, 발동 때 같은 방향·범위로 판정을 켠다. 히트스톱은 기존 scaled time을 정지하므로 준비 시간도 함께 멈춘다. 유효 시간이 끝나기 전에 잘못 설정된 짧은 쿨타임으로 새 공격이 겹치지 않게 한다.

향후 도트 자료가 준비되면 이 상태에 동작을 연결한다. 이번에는 실제 무기 애니메이션이 없으므로 “도트 모션과 명중 프레임 검수 완료”로 보고하지 않는다.

## 검증

**Unity 6000.0.81f1 Play Mode 37/37 통과, 실패·건너뜀 0, 종료 코드 0.** 기존 28개를 수정하지 않고 재통과했고 새 검사 9개가 통과했다. 테스트 본 실행은 약 57.7초다. 새 검사는 입력 방향, 준비 중 무피해, 방향 유지와 후퇴, 피격·전환·비활성·초기화 취소, 히트스톱·짧은 쿨타임, 최신 씬의 사거리 차이와 아델라의 2타 처치를 다룬다.

결과: [playmode-results.xml](../Logs/ReferenceApply/playmode-results.xml), [실행 로그](../Logs/ReferenceApply/playmode-tests.log). C# 컴파일 오류·경고는 검색되지 않았다. Unity 라이선스·서비스 관련 메시지는 남지만 최종 검사는 정상 종료했다. 배치 검증에서만 Burst 컴파일을 비활성화했다. 수동 조작감·렌더링 검수 및 Windows 배포 빌드는 이번 검증에 포함하지 않는다.

변경 전 Assets 전체 해시와 비교해 기존 파일 중 의도한 6개만 달라졌고 삭제된 파일은 없다. 기존 그림·모델·Day 1/2/4 씬·기존 테스트 파일은 동일하다. 새 파일은 테스트 코드와 Unity가 생성한 해당 `.meta`다. 비교 기록: `Logs/ReferenceApply/asset-changes.csv`.

첫 샌드박스 실행은 테스트 진입 전에 Unity 내부 BuildReportRestService 시작 경로에서 충돌하여 정상 권한의 배치 실행으로 재검증했다. 초기 충돌 로그는 `Logs/ReferenceApply/sandbox-startup-crash.log`에 보존했다.
