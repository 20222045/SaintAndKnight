## 기준

마스터 자료: `SaintAndKnight_MCP_Master_20261106_FULL.zip` 및 동일 날짜의 `DOCS.zip`.
승인 이미지의 인상·의상·머리·무기·실루엣을 유지한다.
기존 콘셉트 이미지와 3D 블록아웃을 최종 도트 애니메이션 파일로 간주하지 않는다.

## 먼저 필요한 2D 자료

| 대상 | 준비할 동작 | 연결 시 확인 |
| --- | --- | --- |
| 세실리아 | Idle / Run / Attack / Hit | 사슬 무기 동작과 공격 판정 시점 |
| 아델라 | Idle / Run / Attack / Hit | 장검·방패 실루엣과 공격 판정 시점 |
| 몬스터 A/B | 각 외형과 Idle / 이동 / 공격 예고 / Attack / Hit | 현재 공유하는 훈련 표적 그림을 교체할 때 필요 |

원래 기획의 인게임 키 48px 기준을 출발점으로 삼되 실제 프레임 크기와 무기가 나가는 여백은
디자인을 보고 정한다. 다음 파일 특성이 연결에 필요하다.

- 투명 배경 PNG 또는 스프라이트 시트, 프레임 배치/순서.
- 동작별 동일한 발바닥 기준선과 피벗. 가로 뒤집기를 위한 기본 바라보는 방향.
- 동작별 재생 속도, 반복 여부, 공격이 닿는 프레임.
- 큰 무기 동작 때문에 캔버스가 커져도 몸체 크기가 달라지지 않는 기준.

완료되지 않은 사망/손상 단계 전부를 Day 6 필수 항목으로 늘리지 않는다.
3D HUD 모델·표정·손상 단계는 이후 별도 일정이며 이번 2D 애니메이션 준비와 구분한다.

디자인을 받으면 먼저 프레임/크기/기준선을 확인하고 Animator와 현재 전투 상태에 연결한다.
새 캐릭터 이미지나 동작 프레임을 임의로 생성·수정하지 않는다.
