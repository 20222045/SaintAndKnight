## 이번 요청의 기준

- 현재 게임의 세실리아·아델라 얼굴, 머리, 의상, 체형, 무기를 보존한다. 디테일을 줄이거나 의상을 다른 것으로 바꾸지 않는다.
- 노출을 늘리지 않는다. 성적 동작은 재현하지 않고, 전투 포획·충격·전투 불능 연출로 설계한다.
- 모든 신규 장면에는 도입 동작과 이어지는 움직임이 있다. 정지 그림 한 장으로 완료 처리하지 않는다.
- 점액과 보스 휩쓸기는 현재 연출을 유지한다.
- 제공된 다른 게임의 이미지·GIF는 로컬 관찰용이다. 생성 도구에 업로드하거나 프로젝트에 복사하지 않는다.
- 앞서 생성한 외형 불일치 AI 콘티·시트는 미적용이다. 후속 보스 자세는 현재 게임 원본만 참조한 별도 후보에서 만들었으며, 원본 크기·팔레트와 기존 얼굴 픽셀로 정리했다. [사용한 프롬프트와 처리 범위](BossRevision/POSE_PROMPTS.md).
- 수도사·처형인·회랑 함정은 기존 합성본을 유지한다. 새 보스 자세는 정면에 가까운 서기·웅크림·들림·양팔 벌림·앉음·무릎 꿇기 6종을 사용한다. 촉수는 몸 앞뒤에 나누어 그리고 손목·팔 접점이 자세 변화에 따라 이동한다. 기존 보스 도트 조각을 가로로 여러 번 덮지 않는다.
- 원본 PNG와 기존 .meta GUID, 씬을 보존한다. 추가 시트는 별도 Resources/DefeatMotion 폴더에 둔다.

## 실제 적용 위치와 재생

보스 바닥 촉수·잡기·점액 사망은 해당 패턴을 먼저 보여 주고2초 뒤 공통6종 중 한 장면으로 이어진다. 공통 장면은 죽을 때마다 순환하며, 보스 AI가 치명타 다음 프레임에 공격을 취소해도 선택이 바뀌지 않는다. 바닥 촉수의 실제 타격 콜백으로 휩쓸기 콤보 중 촉수 사망도 구분한다. 휩쓸기 단독 사망은 기존 표시를 유지한다.

포획 중 깊이는 실제 잃은 HP 비율을 읽고, 기존 저항·탈출·피해·물리·입력 시간을 사용한다. 새 사망 애니메이션이 나오면 기존 재시도 키(R 기본값)까지 기다린다. 일반 점액과 새 그림이 없는 경우의 기존 자동 재시도는 유지한다. 화면에 사망 원인·키·상태 글자는 추가하지 않는다.

새 사망 장면만 세계의 어두운 막 앞에 그려 원본 색이 읽히게 했다. R·회복·비활성 때 원래 정렬 순서를 복구한다. 벽은 기존 벽 렌더러 한 곳에서 전체 합성 시트를 그리며 인물을 이중 표시하지 않는다.

후속 수정은 사망 전용 Unlit 소재도 같은 방식으로 복구한다. 패턴 뒤 공통 장면에 들어갈 때는 반복8번 칸부터 재생하여 다시 서는 도입을 반복하지 않는다. 촬영은 일반 사망 색상 갱신 이후 최종 표시 상태를 적용한 후 수행한다. 자세·검증·소재 복구의 최신 기록은 [보스 수정 결과](BossRevision/RESULT.md)가 기준이다.

## 외형 보존 범위

`SaintKnightDay06` 아틀라스, 현재 `boss_pattern`/`enemy_death`, `TrapMotion`, 적의 잡기 도트를 사용하며 원본 파일은 바꾸지 않는다. 보스 후속 수정에는 원본 참조로 생성한6가지 신규 자세를 추가했다. 서기·들림 높이는 세실리아55px/아델라62px, 원본 Idle 팔레트와 원본 머리 도트를 적용한다. 원본 몸을 늘이거나 의상을 벗기지 않는다. AI 보조 자세이므로 모든 신체 픽셀이 원본 그대로라는 주장은 하지 않는다. 사진과의 정량90% 일치율도 측정하지 않았다.

원본 사용 경로와 SHA-256은 [native-manifest.json](native-manifest.json)에 있다. 원본 PNG를 덮어쓰지 않고 새 Resources 폴더에만 쓴다. 기존 씬·원본 그림·기존 `.meta` GUID는 이 작업에서 교체하지 않는다.
