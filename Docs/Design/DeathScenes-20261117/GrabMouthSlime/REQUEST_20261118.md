# 살아 있는 적 잡기·벽 입·바닥 점액 — 2026-11-18

최신 사용자 요청: 살덩이 벽의 입으로 들어가기, 바닥 점액도 구현하기, 처형인과 수도사에 잡혔을 때 참고 사진에 맞춰 적과 캐릭터가 함께 움직이기. 앞서 일반 점액을 유지하라는 지시는 이번 요청으로 갱신된다. 완료된 보스와 회랑 바닥 촉수는 보존한다.

- 사진1: 처형인이 몸을 작게 접어 붙드는 구도. 기존 옆으로 접힌 자세를 살아 있는 잡기·저항에도 연결한다.
- 사진2: 수도사가 낮게 몸을 숙여 캐릭터의 윗팔을 붙드는 전투 제압 자세. 캐릭터는 옷을 입은 채 바닥 쪽으로 낮아지고, 원본 머리·의상·장비를 유지한다.
- 사진3: 바닥 점액이 부츠부터 팔·몸·머리 순서로 감싸는 단계. 현재 게임의 원본 초록 점액 질감으로 구현한다.
- 벽은 벌어지는 입술·치아·입 안을 명확히 표시하고, 그 같은 입 안으로 끌려든 뒤 닫힌다. 기존 수평 흡수 방향을 유지한다.
- 기존 잡기·연타 탈출·내던지기 판정을 사용한다. 실제 Stage1의 처형인 둘은 꺼져 있던 근접 잡기 설정을 켜며, 기존 무기 공격과 아머 규칙은 유지한다. 씬을 재생성하지 않고 해당 설정과 생성 코드만 맞춘다.
- 현재 게임 그림만 사용한다. 참고 사진은 동작 관찰용이며 프로젝트/생성 도구에 복사하지 않는다. 원본 PNG와 기존 GUID를 보존한다.
- 두 캐릭터의 실제 잡기/저항/풀림/사망/R 복귀, 입 흡수와 점액 흡수, 전체 회귀, 실제 카메라 촬영, Windows 빌드와 기동을 확인한다.
