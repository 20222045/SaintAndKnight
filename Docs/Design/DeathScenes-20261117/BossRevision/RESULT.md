# 보스 후속 수정 결과 — 2026-11-17

> 이 문서는 11월17일 적용 이력이다. **11월18일 최신 사용자 지시**에 따라 생성 포즈를 제외하고 원본 전신 도트로 바꿨으며, 보스 공통 마무리는 마지막 사진의 무릎·이마 손·뒤에서 붙듦 자세로 통일했다. 최신 상태는 [접점·원본 그림체 수정](CONTACT_RESULT_20261118.md)이 기준이다.

보스 공통6종과 패턴별 모션을 수정하고, 두 캐릭터의 원인별 사망13종씩 총26종/468칸을 실제 게임에 연결했다. 실행 빌드는 [SaintAndKnight.exe](../../../../Builds/Win64_NativeDefeat/SaintAndKnight.exe)이며 옆의 `SaintAndKnight_Data`와 함께 사용한다. [실제 게임 미리보기](../actual-game-preview.gif).

## 최신 사진6장의 적용

| 사진 | 키 | 적용한 구도·동작 |
| --- | --- | --- |
| 1 | `boss1` | 서 있는 인물을 어두운 촉수가 양옆·뒤에서 세로로 감쌈 |
| 2 | `boss2` | 웅크린 인물을 뿌리 고치가 감싸고 얼굴·옷 입은 어깨가 남음 |
| 3 | `boss3` | 붉은 방사형 뿌리 안에서 팔을 들어 낮게 들림 |
| 4 | `boss4` | 양팔을 좌우로 벌린 채13px 들림, 손목마다 이어진 촉수 |
| 5 | `boss5` | 완전한 복장으로 앉고 높은 뿌리 등받이·위에서 내려오는 덮개 |
| 6 | `boss6` | 무릎 꿇고 앞으로 숙인 인물의 팔·어깨를 뒤에서 붙듦 |

보스 바닥 촉수는 아래에서9px 들어 올리는 별도 동작, 잡기는 원래 피격→팔 들기→양팔 들림으로 연결한다. 점액 뱉기는 현재 게임의 기존 불투명 흡수 시트를 유지한다. 굵은 보스 그림 조각을 가로로 반복해 덮던 방식을 연속 곡선·전후 레이어로 바꾸고, 단계별 손목 접점과 아델라 방패 위치를 보정했다.

수도사·처형인·회랑 바닥 촉수·살덩이 벽의 기존 적용본은 그대로 재검증했다. 일반 점액과 보스 휩쓸기는 사용자 지정대로 유지했다. 여기서 적별 사망 모션은 **각 적·함정에게 당했을 때 플레이어에게 재생되는 장면**을 뜻한다.

## 외형·규격·실행

- 기존 원본 PNG41개의 SHA-256은 이전 커밋 `322f9ca`의 기록과 모두 같다. 현재 베이크 입력37개(기존 소스35+새 자세 후보2)의 해시와26시트 크기도 일치한다. 증빙 `Logs/BossRevision20261117/art-proof.json`.
- 신규 자세는 내장 ImageGen에 **이 게임의 원본 도트만** 참조시켜 만든6자세다. 다른 게임 사진은 전송하지 않았다. 후보는 `Assets/SaintKnightSpriteCook/Art/DefeatPoses/`에 원본 그대로 보존했다. 원본 Idle 팔레트·머리 픽셀을 적용하고 세실리아55px/아델라62px로 맞췄다. [실제 제작 프롬프트·처리 범위](POSE_PROMPTS.md), [전체 장면 프롬프트](../MOTION_PROMPTS.md).
- 128×96px 셀(벽160×112px),48 PPU/Point/무압축/투명. 18칸,8fps, 도입0~7 뒤8~17 반복. 기존 Resources 경로에 추가되어 씬 재부착이 필요 없다.
- 패턴 사망2초 뒤 공통6종을 순환한다. 이때 완성된 잡힘 반복8번 칸부터 이어져 새로 서는 도입이 반복되지 않는다. 일반 보스 원인으로 바로 공통 장면에 들어갈 때는 도입을 정상 재생한다.
- 새 사망은 기본 R까지 유지한다. 사망용 정렬·Unlit 소재는 R/회복/비활성 때 원래 전투용 상태로 복구한다. HP·피해·입력·탈출 시간·씬은 바꾸지 않았다.

캡처 코루틴은 Update 이후, LateUpdate 이전에 재개된다. 기존 촬영은 HP 처리의 일반 사망 색상이 적용된 중간 시점을 담아 인물이 어둡게 보였다. 최종 촬영은 화면의 `SKCharacterSpriteView.LateUpdate`와 같은 표시 갱신을 명시적으로 마친 뒤 현재 카메라를 렌더링했다. 모든 최신 미리보기는 이 최종 캡처에서 만들었다. 촬영 도구만 바뀐 뒤 런타임·빌드 코드는 변하지 않았다.

검증 과정의 이전 로그 `graphics.xml`/`full.xml`/`graphics-final.xml`도 보존했다. 이 표의 `full-final.xml`·`graphics-display-final.xml`이 최종 증빙이다. 같은 프로젝트의 다른 작업은 종료하거나 되돌리지 않았다.
