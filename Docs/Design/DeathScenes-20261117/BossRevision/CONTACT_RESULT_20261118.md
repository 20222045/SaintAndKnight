# 원본 전신·촉수 접점·공통 무릎 자세 — 2026-11-18

> **후속 적용: [실제 보스 앞으로 운반](CARRY_RESULT_20261118.md).** 제자리 공통 자세에 보스까지 이동·세 부위 연결 촉수·고정된 낙하 장비를 추가했다. 아래 검사 수치는 운반 추가 전 이력이다.

사용자가 촉수와 캐릭터의 위치·자세·그림체가 모두 어긋난다고 지적했다. 이후 촉수도 참고 사진과 다시 대조하라고 했으며, 마지막 사진을 보스 공통 사망 자세로 지정했다. 이번 결과는 그 최신 사진을 기준으로 한다.

## 실제 수정

- 이전 생성 포즈를 베이크 입력에서 제외했다. 현재 캐릭터의 전신은 `SaintKnightDay06` 원본 아틀라스의 대기·피격·잡힘·웅크림 도트다. 생성 몸통에 원본 머리만 덮거나 팔레트만 맞추지 않는다.
- 원본 전신을 바탕으로 소매·팔·손·장비를 분리해 관절을 맞춘다. 몸통·복장·얼굴의 원래 픽셀 덩어리를 유지하고, 원본 팔 파츠를 회전·배치하여 붙잡힌 부위가 실제 촉수 위치에 닿게 한다. 공통 자세의 이마 손은 자유롭게 두고 위에 다시 그려 가려지지 않게 하며, 촉수는 윗팔을 붙든다.
- 촉수 목표점만 공유하는 대신 실제로 그려진 성장 곡선의 끝과 줄기 위치를 사용한다. 닿기 전 고리가 따로 떠 있던 부분을 없앴다. 원본 복장 특징 크롭과 손·촉수 픽셀 간격을 별도로 검사한다.
- 보스 **공통6개 키의 최종 자세를 동일한 구도로 통일**했다. 무릎을 낮추고 앞으로 숙임, 이마 쪽에 올린 손, 몸 앞에 굽힌 다른 팔, 등 뒤에서 어깨·윗팔을 붙드는 보스 촉수다. 캐릭터는 보스 반대 방향으로 몸을 숙인다.6개 키의 차이는 작은 반복 위상이다.
- 뒤쪽 촉수는 넓고 빈 아치 대신 등 가까운 덩어리와 팔을 감싸는 가지로 배치했다. 사람 가해자를 새로 넣지 않고 현재 보스의 촉수로 같은 붙드는 방향을 표현한다. 원래 의상은 유지하며 노출·성적 접촉을 늘리지 않는다.
- 세실리아의 무거운 사슬은 내려간 손에 이어진다. 아델라의 사망 장비는 바닥에 놓아 이마 손·앞으로 굽힌 팔을 가리지 않게 했다. 기존 무기·방패 도트를 사용한다.
- 바닥 촉수·보스 잡기·점액의 도입은 구분하며, 패턴 뒤에는 같은 공통 무릎 마무리로 이어진다. 수도사·처형인·일반 점액·벽·휩쓸기의 기존 판정·입력·씬은 변경하지 않았다.
