# 보스에게 가져가는 연출 — 2026-11-18

사용자: 현재의 공통 자세로 보스에게 가져가게 하고, 촉수도 제공한 사진과 다시 대조하여 가깝게 맞추며 위치·자세·그림체 수정도 이어 달라고 요청했다. 기준 커밋 `354709f`.

- 원본 전신·얼굴·복장·기존 손/팔 접점과 이마 손을 유지한다.
- 무릎으로 낮아짐 → 어깨·팔의 포획 유지 → 보스 쪽으로 당겨짐/들림 → 보스 앞에서 같은 자세로 붙들림을 실제 월드 좌표에서 연결한다.
- 보스 쪽 고정점과 캐릭터를 잇는 도트 촉수를 유지하고, 떨어진 장비는 처음 바닥에 남긴다. 넓고 평평한 뒷덩어리는 가늘고 감싸는 가닥으로 다듬는다.
- HP·충돌·입력·적 AI 규칙은 그대로 두고 표시만 이동한다. R/회복/비활성/씬 해제 때 원래 렌더러와 자원을 복구한다.
- 마지막 사진의 공통 무릎 자세가 우선이며, 그림체는 현재 게임 도트를 사용한다. 다른 게임 사진을 생성 도구에 전송하거나 공용 저장소에 복사하지 않는다. 정량95% 일치를 측정한 것처럼 표현하지 않는다.

실제 보스가 함께 보이는 운반 촬영본, 양 방향·두 캐릭터·원인 유지·재시도 복구·전체 회귀 결과로 확인한다. 기존 씬·원본 PNG·기존 GUID·다른 작업의 변경은 보존한다.
