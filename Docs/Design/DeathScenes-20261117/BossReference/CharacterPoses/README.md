# 보스 사망 연출용 캐릭터 포즈

[세실리아 원화](cecilia.png) · [아델라 원화](adela.png)

각 원화는 왼쪽 위부터 대기, 바닥 촉수, 촉수 잡기, 점액 뱉기, 뿌리 고치, 진홍 꽃받침, 장미와 사슬, 겹고리 순이다. 대기는 의상 비교용이다. 나머지 일곱 포즈를 예배당에서 각 캐릭터가 치명타를 받았을 때 재생하는 시트에 넣었다.

| 동작 | 게임에서 보이는 자세 |
| --- | --- |
| 바닥 촉수 | 한 손이 바닥에 닿고 몸의 무게가 낮아진다. 세실리아의 치맛단은 옆으로 퍼지고 아델라의 망토는 뻗은 다리 반대쪽에 쌓인다. |
| 촉수 잡기 | 한 손을 이마에, 다른 손을 앞무릎에 놓는다. 4초 동안 무릎을 고정하고 한 번 더 깊이 숙인다. |
| 점액 뱉기 | 팔뚝으로 눈을 가리고 뒷발로 버틴다. 소매와 철제 팔 보호대의 밝은 면이 얼굴 앞에 보인다. |
| 뿌리 고치 | 몸을 옆으로 접어 두 팔로 얼굴을 감싼다. 껍질 틈 사이로 뺨과 손이 드러난다. |
| 진홍 꽃받침 | 양팔이 벌어지고 골반이 들린다. 세실리아의 옷자락과 아델라의 장화 끝이 아래로 처진다. |
| 장미와 사슬 | 한 손을 좌석 뒤에 짚고 다른 손은 무릎 위에 둔다. 앉은 몸의 무게가 지지하는 팔 쪽으로 실린다. |
| 겹고리 | 무릎과 팔꿈치를 몸 가까이 당기고 턱을 든다. 위쪽 고리 사이로 얼굴이 보인다. |

## 제작과 적용

내장 ImageGen에 각 인물의 승인 초상과 게임 대기 도트를 함께 입력했다. 얼굴은 초상, 전신 복장과 장비는 대기 도트를 기준으로 삼았다. 생성 요청은 같은 성인 캐릭터를 같은 비율의 4열×2행 시트에 그리고, 각 칸에서 접은 무릎·지지하는 손·반대쪽 팔의 위치가 읽히도록 구성하는 것이었다. 세실리아는 은발·금테 베일·겹친 예복, 아델라는 붉은 포니테일·겹견갑·판금 장화의 실루엣을 기준으로 했다.

`python Docs/Design/DeathScenes-20261117/BossReference/CharacterPoses/pack.py`가 배경을 분리하고 128×96 칸의 투명 포즈 아틀라스와 얼굴·팔·장화 좌표를 만든다. Unity 메뉴 `Tools / SaintKnight / Art / Bake Native Defeat Motions`가 이 입력을 프레임별로 변형하고 보스 효과와 합성한다. 포즈별 손과 발도 같은 변형을 거치므로 게임에서 보스까지 이어지는 촉수가 캐릭터를 따라간다.

실제 플레이 화면에서 촬영한 [세 가지 공격](boss-patterns.gif) · [네 가지 공통 연출](boss-finishes.gif).
