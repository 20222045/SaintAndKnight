# Day 9 몬스터와 잡힘 도트

무너진 대성당용 수도사 14프레임, 처형인 16프레임, 수도사와 두 주인공의 잡힘 8프레임씩. 프로젝트에 승인된 세실리아와 아델라 게임 도트를 외형 참고로 사용했다. 기본 이미지 생성 도구로 만들고 게임 크기로 정렬했다.

| 오염된 수도사 | 128×96 | 64 / 92 | 14 |
| 처형인 | 192×112 | 64 / 108 | 16 |

잡힘 PNG 한 셀에는 수도사와 플레이어가 함께 들어 있다. 잡는 동안 수도사의 앞팔이 플레이어 어깨·상완 앞에 겹치고, 내던지기에서는 플레이어가 공중에 뜬다. 붙잡힘은 2장 반복이고 저항은 입력에 맞춰 쓰는 2장이다.

## 검수

- [전투 미리보기](combat-preview.png) 첫 줄은 수도사 대기·할퀴기 예고·잡기 예고·할퀴기다. 수도사 할퀴기 끝은 중심 오른쪽 60px이다.
- 전투 미리보기 둘째 줄은 처형인 대기·베기 예고·회복이다. 첫 대기 자세의 몸체 키는 80px이다.
- 전투 미리보기 마지막 줄은 베기 2장을 세실리아·아델라의 실제 웅크림 도트에 각각 비교한 그림이다. 두 컷에서 앞쪽 낫날 끝은 중심 오른쪽 86px이고, 전방부(x≥120)는 바닥 위 52~59px 및 52~58px이다. 웅크림 도트의 알파 기준 높이는 세실리아 42px, 아델라 48px이다. 발 픽셀과 알파 128을 기준으로 측정했다.
- [잡힘 미리보기](grab-preview.png) 위 두 줄이 세실리아, 아래 두 줄이 아델라다. 각각 덮침 2 → 붙잡힘 2 → 저항 2 → 탈출 1 → 내던지기 1 순서다.
- 범위는 아트와 이미지 검수다. 게임에서 재생하거나 판정과 함께 확인하는 작업은 Unity 연결 단계에 남아 있다.
