# 3D→도트 시험 렌더 (2026-11-19, Claude)

사용자 참고 릴스 Never's End(Hypersect, GDC 2026)의 방식이 우리 도트와 어울리는지 확인한 시험이다. **게임 파일·씬·그림은 건드리지 않았다.**

## 한 일
- [render_test.py](render_test.py): 캡슐로 만든 **대역 인형**(세실리아 비율 55px, 은발·긴 드레스·사슬 철퇴)을 Never's End처럼 처리한다. 128×96 칸 해상도로 바로 그리고, 명암 3단계·1px 외곽선을 넣고, 관절을 픽셀 칸에 맞춘다. 대기 4칸·달리기 8칸·각도 4개(옆 90°, 60°, 30°, 정면 0°).
- 다시 만들기: `python -I Docs/Design/ThreeDPixel/render_test.py` (약 30초)
- 결과물 `out/`:
  - `compare_sheet.png`: 윗줄 = 지금 세실리아(대기 4·달리기 4), 가운데 = 3D 대역(대기 4·달리기 4), 아랫줄 = 같은 달리기 칸의 4개 각도
  - `run_side_by_side.gif`: 지금 달리기와 3D 달리기를 나란히
  - `idle_3d.gif`: 3D 대기

## 보인 것
| | 지금 손 도트 | 3D→도트 |
| --- | --- | --- |
| 크기·픽셀 격자 | 기준 | 같은 칸·같은 크기로 맞음, 흔들림 없음 |
| 디테일(주름·장식·머리결) | 많음 | 모델에 있는 만큼만 나옴. 대역 인형은 장식이 없어 밋밋함 |
| 동작 프레임 | 칸마다 그려야 함 | 포즈만 바꾸면 무한, 각도도 자유 |
| 외곽선·명암 | 손으로 정리됨 | 규칙대로 깔끔하지만 기계적인 느낌 |

결론: **기법 자체는 우리 화면 크기에서 문제없이 작동한다.** 손 도트와 비슷한 품질을 내려면 세실리아 3D 모델의 품질(얼굴·머리 덩어리·옷 주름·장식을 모델이나 텍스처에 넣는 것)이 결정한다. 이 대역 인형으로는 외형을 판단할 수 없다.
