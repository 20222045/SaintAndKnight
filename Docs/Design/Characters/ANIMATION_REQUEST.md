# 전투 도트 여러 장 동작 — 그림 요청서

작성: 2026-11-10. 현재 게임은 동작당 1장(쓰러짐만 12장)이다. 아래 그림이 오면 `make_characters_v5.py`와 같은 방식(v4 느낌, 게임에서 세실리아 55px·아델라 62px)으로 바꿔 끼운다.

## 공통 조건 (가장 중요)

이전에 받은 `cecilia_pixel_collapse.webp`·`adela_pixel_collapse.webp`처럼 만들면 변환이 가장 잘 됐다.

- 한 시트에 **한 캐릭터·한 동작**, 프레임은 **같은 크기 칸에 한 줄**로(칸 번호 F00, F01… 있어도 됨).
- **옆모습, 오른쪽을 바라봄**. 모든 칸에서 캐릭터 **크기 동일**, **발이 같은 바닥선**에 닿음(점프 제외).
- 배경은 **투명** 또는 **단색**(기존 변환용 시트와 같은 어두운 보라, 그라데이션·바닥 장식·먼지·글자 없이).
- 캐릭터 키는 칸 안에서 **약 180px 이상**(지난 시트 수준). 작으면 화질이 떨어진다.
- 무기 전체가 칸 밖으로 잘리지 않게. 공격 궤적(빛 줄기)은 **넣어도 되지만**, 넣으면 그 끝이 실제 판정 끝이 된다.
- **PNG 파일 경로**로 전달(채팅에 붙이면 webp로 압축됨).
- 외형은 승인 디자인 그대로: 세실리아(백금발·파란 눈·흰 베일/드레스·금 장식·사슬 철퇴), 아델라(진홍 포니테일·호박 눈·강철 갑옷·붉은 망토·장검·금 십자 연 방패).

### 시트 전달과 게임에서의 확인

- 파일명은 `<캐릭터>_<동작>_fNN.png` 또는 같은 순서의 한 줄 시트로 전달한다. 예를 들어 `cecilia_run_f00.png`, `adela_jump_fall_f01.png`처럼 이름을 붙인다. 원본 시트의 칸 크기와 발 기준선을 맞추고, 공중 프레임은 같은 정렬축을 기준으로 다리만 움직여 캐릭터 전체가 이중으로 떠오르는 현상을 막는다.
- 게임용 출력은 128×96px 투명 PNG, 48 PPU, Point, 무압축을 사용한다. 선 자세 몸체 높이는 세실리아 55px·아델라 62px, 가로 기준은 x64, 지상 발 기준선은 상단에서 y92다. 기존 Unity 피벗 `(0.5, 0.26625)`를 적용해 발을 콜라이더 바닥에 맞춘다.
- 준비·타격·마무리와 피격은 실제 상태 시간에 맞춰 프레임을 고르고, 히트스톱 동안 표시 진행도 멈춘다. 그림은 판정 이벤트 없이 `SKCharacterSpriteView`에서 상태를 읽어 표시한다.
- 달리기 접지와 루프 연결, 타격 중 무기 끝과 판정 앞끝, 좌우 반전, 짧은 점프, 공중 공격, 전환 취소, 잡힘 탈출·내던지기, HP 단계 전환을 각각 화면에서 확인한다.

## 받은 뒤 할 일 (Claude)

1. 프레임 칸 위치 측정 → 배경 제거 → 같은 배율 축소 → 캐릭터별 공용 색으로 정리(v4 값).
2. `SKCharacterSpriteView`를 동작별 여러 장 재생으로 확장: 대기·달리기는 반복, 준비·타격 장면은 **전투 시간에 맞춰 늘이거나 줄임**(그림이 판정 시간을 정하지 않음, Animator 없음).
3. 공격 타격 장면 중 가장 앞 픽셀 = 판정 앞끝 검사 유지(`HitboxFarEdgeMatchesDrawnWeaponTip`).
4. Play Mode 회귀 검사 + 화면 캡처로 확인.
