## A. 기본 동작 (필수 — 게임 내내 보이는 것)

### 1. 대기 `idle` — 4칸, 반복
```
제자리에 서서 천천히 숨쉬기. 가슴과 어깨가 살짝 오르내리고 머리카락(세실리아는 베일, 아델라는 망토)이 아주 조금 흔들림. 처음과 마지막 칸이 자연스럽게 이어지게.
```

### 2. 달리기 `run` — 12칸, 반복
```
오른쪽으로 달리기 한 주기. 다리를 크게 교차하고 팔을 앞뒤로 흔듦. 머리카락과 옷자락이 뒤로 날림. 무기는 손에 쥔 채 유지. 처음과 마지막 칸이 자연스럽게 이어지게.
```

### 3. 공격 준비 `windup` — 3칸
- 세실리아
```
사슬 무기를 휘두르기 직전 동작. 몸을 살짝 뒤로 비틀며 사슬을 쥔 오른팔을 뒤로 당김. 사슬이 몸 뒤로 늘어짐.
```
- 아델라
```
장검을 내려치기 직전 동작. 장검을 두 손이 아닌 한 손으로 어깨 위로 높이 들어 올리고 방패는 몸 앞에 둠. 무게를 뒷발에 실음.
```

### 4. 공격 타격 `attack` — 3칸
- 세실리아
```
사슬을 앞으로 빠르게 채찍처럼 휘둘러 몸 앞으로 곧게 뻗음. 사슬 끝이 몸에서 한 뼘 이상 앞까지 닿음. 앞발을 내딛음.
```
- 아델라
```
장검을 앞으로 크게 내려 벰. 칼끝이 몸 앞 아래쪽까지 호를 그림. 앞발을 크게 내딛고 방패는 몸 앞에 유지.
```

### 5. 공격 회수 `followthrough` — 4칸
- 세실리아
```
뻗었던 사슬을 손으로 감아 거둬들이며 원래 대기 자세로 돌아옴.
```
- 아델라
```
내려친 장검을 다시 들어 올려 몸 앞에 세우고 원래 대기 자세로 돌아옴.
```

### 6. 피격 `hurt` — 5칸
```
앞에서 맞아 몸이 뒤로 젖혀지며 한 걸음 밀려남, 얼굴을 찡그림, 다시 자세를 잡음.
```

### 7. 점프 `jump` — 8칸 (도약 → 상승 → 정점 → 낙하 → 착지)
```
무릎을 굽혀 힘을 모음 → 위로 도약 → 공중에서 무릎을 모음 → 정점 → 다리를 뻗으며 낙하 → 착지하며 무릎을 굽힘. 머리카락과 옷자락이 움직임에 따라 위아래로 날림.
```

### 8. 웅크리기 `crouch` — 1~2칸, 유지
```
무릎을 깊게 굽혀 낮게 웅크림. 머리 높이가 서 있을 때의 3분의 2 정도. 무기는 손에 쥔 채 몸 앞에 둠.
```

### 9. 쓰러짐 `collapse` — 6칸, 마지막 칸 유지
```
힘이 빠져 무릎을 꿇고 → 앞으로 손을 짚었다가 → 옆으로 쓰러져 누움. 마지막 칸은 바닥에 누운 채 움직이지 않음. 옷은 그대로.
```

## B. 손상 대기 (HP가 줄었을 때 서 있는 모습) — 각 4칸 반복, 총 4종

HUD 1~4단계와 맞춘다. 옷 손상 정도는 HUD 그림을 따라가고, 여기서는 **자세·표정만** 적는다.
```
1단계: 대기와 같은 자세지만 숨이 조금 거칠고 어깨가 살짝 내려감.
2단계: 상체를 조금 숙이고 한 손으로 옆구리를 감싸며 거친 숨.
3단계: 무릎이 살짝 꺾이고 몸이 앞으로 기울어짐, 무기를 겨우 쥠, 지친 표정.
4단계: 겨우 서 있음, 무릎이 떨리고 무기 끝이 바닥에 닿음, 곧 쓰러질 듯한 표정.
```

## C. 잡힘 (적 수도사에게 붙잡힐 때)

붙잡는 적은 **그리지 않는다**(게임에서 적을 따로 겹쳐 그림).

### 10. 덮쳐짐 `pounced` — 7칸
```
앞에서 누군가 달려들어 붙잡히는 순간. 몸이 뒤로 휘청이고 → 두 팔이 몸통에 붙들린 듯 옆구리에 붙고 → 발이 바닥에서 살짝 뜸. 놀란 표정.
```

### 11. 붙들림 `held` — 4칸, 반복
```
두 팔이 몸통에 붙들려 꼼짝 못 하는 상태. 발끝이 바닥에서 살짝 뜬 채 몸이 굳어 있고 작게 떨림.
```

### 12. 저항 `resist` — 9칸, 반복
```
붙들린 채 어깨와 팔을 좌우로 세게 비틀고 다리를 버둥거리며 빠져나오려 함. 이를 악문 표정.
```

### 13. 탈출 `escape` — 9칸
```
팔을 크게 뿌리쳐 빠져나옴 → 앞으로 두어 걸음 비틀거림 → 다시 무기를 쥐고 대기 자세로 섬.
```

## D. 함정 반응

### 14. 바닥 촉수에 찔림 `spikehurt` — 3칸
```
발밑에서 무언가 솟아 찔려 몸이 위로 튀어 오르듯 움찔하고 한쪽 다리를 들어 올림.
```

### 15. 점액 위 걷기 `slimewalk` — 4칸, 반복
```
발이 끈적한 바닥에 달라붙어 한 걸음씩 힘겹게 떼며 천천히 걸음. 발을 들 때 무릎을 높이 들어 올림.
```

### 16. 점액 위 대기 `slimeidle` — 2칸, 반복
```
끈적한 바닥에 발이 붙어 서서 발을 빼려고 살짝 힘을 줌, 불편한 표정.
```

## E. 보스·적 전용 칸 (선택 — 지금 Codex 원화가 있으니 바꾸고 싶을 때만)

보스나 적은 **그리지 않는다**.

```
보스 휩쓸기 피격 (4칸): 옆에서 크게 맞아 발이 바닥에서 떨어지며 뒤로 날아가 → 바닥에 떨어져 → 쓰러짐.
보스에게 들어 올려짐 (1칸): 허리가 붙들려 공중에 들어 올려진 채 팔다리가 축 늘어짐.
보스에게 들린 채 저항 (3칸, 반복): 공중에 들린 채 팔다리를 버둥거림.
보스에게서 풀려남 (1칸): 공중에서 떨어져 무릎으로 착지.
보스에게 쓰러짐 (2칸): 무릎을 꿇고 → 앞으로 엎드려 쓰러짐.
수도사에게 쓰러짐 (4칸): 뒤에서 붙들린 채 힘이 빠져 무릎이 꺾이고 고개를 떨굼.
처형인에게 쓰러짐 (4칸): 맞아서 앞으로 엎어지며 쓰러짐, 마지막 칸 유지.
```

함정 포획·흡수(점액·촉수·살덩이 벽)와 보스 사망 연출 전용 시트는 이 목록에 넣지 않았다. 지금 Codex 원화를 쓰고 있고, 옷은 벗기지 않는다는 규칙이 있다. 바꾸려면 따로 정한다.
