## 등장 컷과 3D

- [등장 컷](rose_madonna_intro.png)은 887×1774 투명 PNG다. 화면 위에 얹을 3D풍 이미지를 기본 이미지 생성 도구로 별도 제작했다.
- [GLB 블록아웃](rose_madonna_blockout.glb)은 높이 4.58m, 정적 메시 7개, 삼각형 64,329개, 컬러 PBR 재질 14개다. Y-up, +Z 정면, 발 기준 y0. 심장 껍질은 별도 메시다. [실제 GLB 렌더](rose_madonna_model_preview.png)
- 검수 범위는 이미지 프레임·알파·도트 크기·GLB 구조다. 보스 전투와 애니메이션 연결, 설정서 우선순위 2~3의 후속 모션은 제작 범위에 남아 있다.
