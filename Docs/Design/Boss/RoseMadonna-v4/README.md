# 장미창의 성모 전신 도트

사용자가 제공한 전신 일러스트를 ImageGen 내장 도구로 편집했다. 1페이즈는 원본의 베일, 후광, 묵주와 드레스를 유지한다. 2페이즈는 붉은 후광과 옷에 비친 붉은 빛으로 구분한다. 처치 상태는 부서진 후광 아래 무릎을 꿇은 포즈다.

**게임 적용(2026-11-10, Claude, 사용자 승인):** `python Docs/Design/Boss/RoseMadonna-v4/fit_to_game.py`가 아래 원본을 게임 칸으로 만든 뒤 게임 톤으로 색을 낮추고(후광·얼굴은 밝기 유지), 치맛단을 덮는 살덩이 뿌리·심장 자리·치마를 타는 뿌리(1페이즈), 허리까지 차오른 살덩이·드레스 핏줄(2페이즈), 말라붙은 뿌리(처치)를 더해 `boss_body_*`에 쓴다. 지금 게임 그림은 이 결과다. 아래 가져오기 스크립트는 보정 없는 원본 칸만 만든다(되돌릴 때). 살덩이 도구는 `../flesh_tools.py`.

프로젝트 루트에서 `python Docs/Design/Boss/RoseMadonna-v4/import_rose_madonna.py`를 실행하면 `source_*.png`를 Unity용 몸 프레임 5장으로 내보낸다. 셀은 256×300, 48 PPU, 중심 x=128, 바닥은 셀 하단이다. 대기 그림은 240px와 242px를 번갈아 쓰며 발 기준선을 공유한다. 치맛자락에 겹쳐 그리는 심장은 바닥에서 36px 위에 있다.

`../make_boss_sprites.py`는 이전 고치형 몸과 심장·촉수·점액을 출력하는 생성기다. 해당 이펙트를 다시 출력한 뒤에는 이 폴더의 가져오기 스크립트를 실행해 전신 몸 5장을 복구한다.
