# 시니시스타 2차 심층 분석과 업그레이드 — 2026-11-08

사용자 요청: “5일차까지 한 것을 보고, 시니시스타1 레퍼런스로 부족한 부분을 심층 분석해서 업그레이드”.
범위: Day 1~5 기능 보강. **Day 6 도트 연결은 여전히 디자인 준비 대기**이며 이번 작업으로 시작하지 않았다. 새 그림·음원·모델은 만들지 않았다.

## 1. 이번에 새로 확보한 증거

1차 분석(2026-11-07)은 CIL 메타데이터 일부만 읽어서 **조작 규칙의 세부(점프·공중 이동·공격 중 이동·잡기)가 비어 있었다.** 이번에는 ILSpy CLI로 `Assembly-CSharp.dll` 전체를 디컴파일해 해당 클래스 본문을 직접 읽었다. 디컴파일 결과는 세션 임시 폴더에만 두었고 **프로젝트에 원작 코드를 한 줄도 넣지 않았다.** 아래는 구조·규칙 요약이며 변수값 대부분(씬 직렬화 값)은 `StreamingAssets/game_bin`의 암호화된 번들 안에 있어 **수치는 미확인**이다. 암호화 해제는 하지 않았다.

| 원작 구조 (디컴파일 확인) | 의미 | 우리 Day 1~5 상태 |
| --- | --- | --- |
| `JumpAction`: 초속 + 버튼 유지 중 추가 속도(sustain), 착지 후 버튼을 떼야 재점프 | **누르는 시간으로 점프 높이 조절** | 고정 높이 → **이번에 적용** |

| `KnockBackAction`: 각도·세기로 포물선, 착지까지 넉백 유지, 넉백 중 경직·무적 타이머 정지 | 넉백 중 연속 피격 방지 | 현 0.55초 무적으로 충분, 변경 없음 |
| `PlayerManager.hpState`: HP 비율 2개 임계값 → 녹/황/적 3상태 | 초상 상태 | 우리는 0~4단계(유지) |

웹(나무위키 원문, 2026-09-06 수정판)으로 교차 확인한 것: 길게 누르면 높은 점프, 공중 이동 약간 느림, 지상 공격 중 이동 불가·점프 공격은 이동 가능, 활은 홀드 중 점프/근접으로 취소. 1스테이지 첫 보스는 근접 일격 위험 + 등불 기믹. 잡힘 연타 탈출은 일부 적 사례로만 서술되어 있어 일반 규칙은 디컴파일 근거가 더 강하다. 나무위키에는 HP 표시·체크포인트 상세가 없다.

## 2. 이번에 적용한 업그레이드 (Day 5 씬에서만 켜짐)

모든 새 값은 **직렬화 필드이며 코드 기본값은 기존 동작**(점프 배율 1, 공중 배율 1, 잡기 꺼짐, 자동 재시도 0)이다. Day 1/2/4 씬은 그대로 동작한다. Day 5 씬에는 해당 YAML 줄만 추가했고 GUID·다른 값은 그대로다. `SKEnemySceneBuilder`도 같은 값을 쓰도록 맞췄다.

| 기능 | Day 5 임시 값 | 플레이 변화 |
| --- | --- | --- |
| 가변 점프 | 상승 중 Space를 떼면 상승 속도 × 0.45 | 짧게 누르면 낮은 점프(테스트상 0.3 이상 차이), 길게 누르면 기존 최대 높이 |

수치는 원작 실측이 아니라 우리 프로토타입 값이다(원작 값은 암호화 번들 안에 있음). 잡기는 비노골적인 구속·HP 감소로만 구현했고 연출은 추가하지 않았다. 향후 Day 15 정신 침식이 “잡힘”을 입력으로 쓸 수 있도록 상태를 분리해 두었다(`SKGrabState`).

### 기존 계약과의 관계

- 입력 소유자는 여전히 `SKDay01Player`: 잡힘 중 연타 입력도 여기서 읽어 `SKGrabState.RegisterStruggle()`로 넘긴다.
- `SKCombatState`에 `Held`를 **끝에 추가**(기존 숫자값 불변). 우선순위 Disabled → Dead → **Held** → Hurt → Windup → Attacking → Recovery → Ready.
- 잡히면 준비 중 공격 취소, `R`/`ResetCombat`/비활성/사망은 잡힘을 해제. 취소된 공격이 되살아나지 않는 계약 유지.
- `SKHealth.Drain`은 HP만 깎고 `Changed`만 발생(경직·무적·히트스톱 없음). 내던지기는 기존 `TryTakeDamage` 경로.
- `SKEnemyState`에 `GrabWindup`, `Holding`을 끝에 추가.
- 공격 중 이동·점프 허용, 전환 시 쿨타임 보존은 **바꾸지 않았다.**

튜닝 후 같은 봇의 결과: 세실리아는 사거리로 A·B를 무피해로 처리(거리 캐릭터 역할 유지). 아델라는 A의 공격을 받을 수 있게 됐고(−15), B의 예고에 공격을 겹치면 −50까지 맞는다(“B 예고 중에는 때리지 말 것”이 학습 대상이 됨).

**지상 공격 발 묶기 판단 근거:** 공격하며 물러날 수 있는 지금 방식이 이득을 주는 경우는 없었다. 세실리아는 물러나도 피해가 0이고 처치만 늦어졌다. 아델라는 물러나면 짧은 사거리 밖으로 나가 헛치고 맞았다(A −15, B 사망). 지금은 악용할 구멍이 아니므로 **계약을 바꿀 근거가 약하다.** 사람의 플레이로는 다를 수 있다.

**남은 문제 (미적용, 사용자 판단):** 1:1에서는 붙어서 연타하는 봇이 A(약 0.9초)·B(약 1.5초)를 공격을 받기 전에 처치한다. 적 체력이 예고 시간보다 빨리 깎이기 때문이다. 해결 후보는 A/B HP 상향(승인된 처치 타수 3/4·2/3 변경), 적 2마리 동시 배치, 몸통 접촉 위협이다. 처치 타수는 승인된 Day 5 프로필이라 바꾸지 않았다.

추가 코드: `SKEnemyAgent`의 `hurtRecoverySeconds`(음수 = 기존 recoverySeconds), `strikeArmored`, `grabWindupArmored`. 기본값은 기존 동작이다. Day 5 값: A 0.3 / false / true, 잡기 예고 0.45. B 0.5 / true / –.
검증: 회귀 **50/50 통과**(기존 37 + 업그레이드 13). 측정용 4개는 건너뜀. 종료 코드 0, 컴파일 경고 없음. `Logs/ClaudeRuns/20261108_005555/`.
