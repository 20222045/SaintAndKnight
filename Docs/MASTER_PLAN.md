## 변경 금지 및 구현 원칙

1. 확정된 캐릭터 디자인을 임의로 변경하지 않는다.
2. 기존 GLB를 우선 사용한다. 새 모델 제작을 요청하거나 임의 교체하지 않는다.
3. 실제 전투는 2D 도트 횡스크롤 액션이다. 측면 상태 HUD는 2D 전신 일러스트를 사용한다(2026-11-10 사용자 결정, 3D 모델 사용 보류).
4. 체력 기반 외형 손상 0~4단계를 유지한다. “정신 붕괴”는 별도 수치가 아니라 HP가 깎이는 모습의 이름이다(2026-11-12 사용자 결정, `Docs/DAY15.md`).
5. 기존 기능을 삭제하거나 처음부터 다시 제작하지 않는다.
6. 모델 존재 및 리깅·임포트 상태를 검증하기 전 완료로 간주하지 않는다.

기존 모델명: `Cecilia_blockout_NOT_FINAL.glb`, `Adela_blockout_NOT_FINAL.glb`.
임시 모델이지만 사용자가 디자인을 유지하기로 결정했다.

## Day 2 — 2D 전투 시스템 기초

목표: Day 1 기능을 유지하면서 기본 공격과 피격 구현.

- 기존 프로젝트 구조와 Day 1 스크립트 확인.
- 기본 공격 입력과 세실리아·아델라 각각의 공격 판정.
- 공격 Hitbox와 피격 Hurtbox 분리.
- 임시 적 또는 훈련용 표적 1개.
- 적중 시 표적 HP 감소, 적 공격 시 플레이어 HP 감소.
- 짧은 피격 반응 및 중복 타격 방지.
- 실제 플레이어 HP와 기존 HUD 동기화.
- 공격 중 캐릭터 전환·점프 검사, Unity Console 컴파일 오류 확인.

완료 기준: A/D·Space 유지, 전환 후 공격·체력 정상, 양방향 피해 처리,
HUD 실제 HP 반영, C# 컴파일 오류 없음.

범위 제외: 캐릭터 리디자인, 새 3D 모델, 보스 완성, 전체 스테이지, 붕괴 컷신 완성.
